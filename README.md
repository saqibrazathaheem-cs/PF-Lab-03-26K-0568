**Lab Title:** Data Types, Format Specifiers, and Input/Output in C

## Introduction

This lab focuses on the foundations of C programming, including primitive data
types, format specifiers, escape sequences, and character/string input-output
functions such as `scanf()`, `printf()`, `getchar()`, `putchar()`, `fgets()`,
and `puts()`. It also covers Git and GitHub workflows such as branching,
committing, and pull requests.

## Objectives

1. Understand and use C's basic data types (`int`, `float`, `double`, `char`,
   `bool`, `void`).
2. Practice using format specifiers to display data in different bases and
   precisions.
3. Learn character and string input/output functions in C.
4. Understand how floating-point precision affects displayed output.
5. Apply Git and GitHub workflows: branching, committing, pull requests, and
   merging.

## C Topics Covered in Lab 03

- Data types and variable declarations
- Format specifiers (`%d`, `%f`, `%c`, `%s`, `%x`, etc.)
- Input/output functions (`scanf`, `printf`, `getchar`, `putchar`, `fgets`, `puts`)
- Escape sequences
- Floating-point precision formatting
